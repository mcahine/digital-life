# digital-life 需求规格

## R1 统一格式
不论数据来自 PC 还是手机、不论原始是 SQLite/CSV/zip，落到**一张 event 表**。
`device` 与 `source` 是字段，不是分区。

## R2 单一时间轴
所有事件以 UTC 毫秒排序；切片落在全局时间轴上，跨设备同一时刻可并列比较。

## R3 数据库优先
ManicTime 的 `Ar_Activity` 四条时间线（ComputerUsage / Applications / Documents / Tags）是结构化骨架来源。
截图（视觉模型）只允许补 `overall_summary` / `key_actions[].detail` / `image_descriptions`，
不得改写 DB 给出的应用与时间；冲突以 DB 为准并计入 `conflict_count`。

## R4 只产日总结
`daily_summary` 只有「日」这一层。周/月/季/年由日记系统负责。本模块**不写** `04-Areas/GTD/50-回顾/`。

## R5 清洗可解释
每个源必须产出「输入行数 → 输出行数」的差额与原因分布（`clean_report.json`）。
去重规则见 design.md §4（C1–C13），每条都要有实测依据。

## R6 幂等
同一源重跑两次，`event` 行数不变；`publish` 两次，manifest 的 sha256 与行数一致。

## R7 代码/数据分离
代码只在本目录。**给人看的数据落 `04-Areas/数字人生/`**（`10-时段/`、`20-日报/`、`_index/manifest.json`）；
**大体量中间物落 `知识库/.data/digital-life/`**（库、NDJSON、解包件），vault 不承载可重建的中间物。
原始件在 `00-Inbox/` 原地读，不搬不复制。

## R8 明确报错
缺源文件、缺依赖、模型未配置 → 抛异常并写清「怎么修」，不静默降级。

## R9 截图策略
ManicTime 截图全量（55,527 张）进切片，**不做关键帧去重**（1 分钟/张已是粗粒度）。
切片 15 分钟一窗，单窗超 24 张图时递归二分。

## R10 留存包
生成物打包到 **`.data/digital-life/exports/`**：NDJSON 全量导出 + manifest（sha256/行数/覆盖区间）+ zip。
manifest.json 单独放 `04-Areas/数字人生/_index/`（`/api/dl/stats` 读它，缺则 503）。

## R11 两层加工（2026-10-22 增补）
片层（`slice_result`）由视觉模型写**完整**总结，不截断、不加省略号；
日层（`daily_summary`）由模型对当天所有片层总结做**二次总结**，输出自然段叙事。
Python **只搬运原料**，禁止用模板把时间轴罗列成日报。

## R12 全量明细归时段网页（2026-10-22 增补，用户裁决）
日报**只写突出部分**（前 6 应用 + 前 5 域名各一句 + 压缩时间线），
**全量明细一律归时段网页** `10-时段/YYYY-MM-DD.html` —— **一天一个 HTML 文件**。

> 2026-10-22 用户裁决，**推翻**同日早先的「每天一个日期文件夹 + 9 页」：
> 「`10-时段/` 里不要再以日期为名然后存多个 HTML 文件了，直接一个 HTML 包含一天的信息，
> 参考 `00-Inbox/index.html` 是怎么做的，这个除了文件命名不是对应日期，其他都挺好」。
> 片层 md 迁到 `10-时段/片层/YYYY-MM-DD/`，与网页互不干扰。

单页结构：header（日期 + 星期 + 规模统计）→ 时间线 / 应用 / 网站 / 视觉 四个 section，
section 内部按设备 tab 切换，右下 fab 目录浮钮跳锚点。

- **设备一律显示真实设备名**（`D-001` / `iQQQZ3`），不用「电脑 / 手机」——
  用户 2026-10-22：「电脑和手机完全没必要，就展示设备名就好」。
- **视觉段只要文字**，不展示截图，也不写「截图 N 张」这类读图过程量。
- **网站段要能看到页面级记录**：每次访问一行，锚文本优先用页面标题，
  没有标题才退成「域名 · 路径末段」；**整条 URL 不得上屏**。

- 网页是**只读渲染层**：数据实时取自 `event / slice / slice_result`，不落中间 JSON，删掉 html 可重建。
- **一个时间戳就够**：同区间的浏览器窗口行与网页行合并为一行，第一条网页当整行链接，其余进缩进子行。
- **「代表页面」这一列不存在**：网站页只到域名粒度 + 每域名全量页面清单。
