## 怎么用这些复盘

**不要**把它们当规范读——规范在 `AGENTS.md §C`，那里是收敛后的结论。
这里的价值是**定位过程**：同样的症状再出现时，能从「当时怎么排除的」快速对上号。

典型场景：

- 又见 `413 payload too large` → 看 `413-degenerate-image-*.md`，先查畸形图而不是减体积
- 重建突然变慢 → 看 `perf-regression-*.md`，先 EXPLAIN 看索引有没有走对
- 429 大量出现 → 看 `quota-and-ratelimit-*.md`，先读 `message` 判限流还是耗尽
- 想改片层文体 → 看 `diary-style-*.md`，**先想清楚改哪一层**
